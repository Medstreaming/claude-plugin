Get started

Install and sign in

/plugin marketplace add https://github.com/Medstreaming/claude-plugin

/plugin install med@medstreaming

az login --allow-no-subscriptions

Settings

Press Enter to accept each default for org, project and output folder.

Tools needed

Azure CLI with the DevOps extension, Git, MSBuild and sqlcmd.

For UI tests

Edge or Chrome and Node.js. Playwright installs on first run.

Med task workflow · 9

Setup takes a few minutes. The prerequisites are not checked at install, so sign in to Azure DevOps first. The third command is only needed if az is not already signed in.
