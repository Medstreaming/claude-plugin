The commands

Six commands cover the lifecycle

1 · Plan

/med:plan-epic

Epic to requirements, task breakdown and UI mockups.

2 · Plan

/med:plan-task

Work item to a reviewed plan, saved as Markdown and HTML.

3 · Build

/med:implement-task

Builds the saved plan, runs the verify scripts, updates the docs.

4 · Review

/med:code-review-task

Finds every commit for the task and reviews each distinct change.

5 · Test

/med:create-test-task

Test cases from the criteria, then a linked Verify task.

6 · Test

/med:play-test

Runs the cases in the web client with a screenshot for each.
